# Utility Library

## Project Overview

Utility Library is a collection of reusable C++ helper libraries designed to provide commonly used functions that can be shared across multiple projects.

The main goal of this project is **Code Reusability** — instead of rewriting the same functionality in different projects, these libraries provide a centralized collection of helper functions that can be easily included and reused whenever needed.

This project serves as a foundation for building and expanding personal C++ libraries for future projects.

## Available Libraries

The project includes the following libraries:

- **clsDate:** Provides date-related operations and utilities.
- **clsPeriod:** Provides operations for working with date periods.
- **clsString:** Provides commonly used string manipulation functions.
- **clsUtility:** Provides general-purpose helper functions and utilities.

## Key Concepts

- Code Reusability.
- Organizing common functionality into separate libraries.
- Using header files to share functionality across projects.
- Building reusable components that can be extended over time.
