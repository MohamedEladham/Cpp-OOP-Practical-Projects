# C++ OOP Practical Projects

## About This Repository

This repository contains practical C++ projects developed while learning and applying **Object-Oriented Programming (OOP)** concepts.

The main purpose of this repository is to apply programming concepts through practical work, build reusable components, improve code organization, and gain experience in developing projects step by step.

The projects are organized to reflect different learning goals, from building reusable helper libraries to developing larger applications using OOP principles.

## Projects

### 001. Utility Library

**Path:** `001_Utility_Library/`

A collection of reusable C++ helper libraries designed to provide commonly used functions that can be shared across multiple projects.

The main focus is **Code Reusability**, reducing code duplication, and building a personal collection of reusable components.

**Included Libraries:**
- `clsDate`
- `clsPeriod`
- `clsString`
- `clsUtility`

[View Utility Library](001_Utility_Library/README.md)

### 002. Bank Management System Using OOP

**Path:** `002_Bank_Management_System-OOP/`

A practical C++ project developed to apply OOP concepts through a gradual development process.

The project is divided into ten development stages, starting with basic client operations and progressing toward a more complete banking system.

**Development Stages:**
1. Find Client
2. Update Client
3. Add Client
4. Delete Client
5. List Clients
6. Total Balances
7. Main Screen
8. Transactions
9. Manage Users
10. Login & Permissions

The project demonstrates the gradual development of a larger application, code reuse between stages, and the integration of different components into one system.

[View Bank Management System Using OOP](002_Bank_Management_System-OOP/README.md)

## Key Learning Areas

Through these projects, this repository focuses on:

- Object-Oriented Programming concepts.
- Classes and Objects.
- Encapsulation and Inheritance.
- Code Reusability.
- Organizing code into reusable components.
- File Handling.
- Building and extending projects gradually.
- Integrating different components into larger applications.

## Development Approach

The projects follow a practical learning approach:

- Build projects based on the concepts being studied.
- Divide larger projects into smaller, manageable stages.
- Develop and test each stage before moving forward.
- Reuse previously developed components whenever possible.
- Keep the code organized and easy to maintain.
- Expand projects gradually as new concepts are learned.

This repository serves as a record of my practical journey in learning C++ and applying Object-Oriented Programming.
